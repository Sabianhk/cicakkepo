Privacy Policy

Cicak Kepo · Last updated 17 November 2026

This policy covers the "Cicak Kepo" Google OAuth app, a private upload tool used only by the owner of the YouTube channel @CicakKepoChannel.

What the app accesses

With the owner's consent, the app uses the Google Drive API to search one Drive folder for a file with the same name, then create or update video files in that folder.

What the app stores

The OAuth token is stored only on the owner's own computer, in a file readable only by that user. The app has no server and no database, and it keeps no analytics or logs of Google user data anywhere else.

Sharing

Google user data is not sold, shared, or transferred to any third party. It is not used for advertising, and it is not used to train AI or machine-learning models.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access makes the stored token useless.

Contact

Questions: contact the channel through YouTube.
